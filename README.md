Anomaly Detection Demo
This notebook demonstrates basic anomaly detection techniques using statistical methods and visualizations. It’s part of my machine learning portfolio focused on identifying outliers in datasets — a critical step in data cleaning and unsupervised learning.

Objectives
- Visualize data distribution using boxplots
- Detect outliers using IQR (Interquartile Range)
- Standardize data and compute Z-scores
- Interpret statistical thresholds for anomaly detection

Tech Stack
- Language: Python 3
- Libraries: NumPy, Matplotlib
- Tools: Jupyter Notebook

Techniques Used
1. Boxplot Visualization
- Highlights data spread and potential outliers
- Easy visual cue for anomaly detection
2. IQR Method
- Calculates Q1, Q3, and IQR
- Flags values outside 1.5×IQR as outliers
3. Z-Score Method
- Standardizes values
- Identifies data points far from the mean
